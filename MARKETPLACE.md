# RapidReact

Speed up your React and TypeScript workflow with practical snippets for everyday UI, form, utility, and data-fetching tasks.

## Highlights

- React component, hook, form, and list snippets
- React Hook Form and Zod starters
- Reusable utilities such as debounce, clipboard, storage, and formatting helpers
- Axios request helpers and page templates
- TanStack Query setup and data-fetching patterns

## Great for

- Building React components faster
- Creating forms and API-backed pages quickly
- Reducing repetitive boilerplate in TypeScript projects

## Try it

Open a TypeScript or TSX file and start typing:

- `rr.state`
- `rr.formpage`
- `rr.usefetch`
- `rr.axios.get`
- `rr.tq.query`
