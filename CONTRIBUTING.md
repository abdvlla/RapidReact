# Contributing to RapidReact

Thanks for your interest in improving RapidReact. Since i am still a developer early in my career, all feedback, suggestions, and help would be much appreciated!

## How contributions work

We welcome ideas, bug reports, and code contributions. However, all changes should go through a review process before they are merged.

## Ways to contribute

- Report bugs or suggest improvements by opening an issue
- Suggest new snippets or workflow ideas
- Submit a pull request with a code change

## Before you submit a pull request

1. Fork the repository
2. Create a branch for your change
3. Make your changes locally
4. Run the available checks
5. Open a pull request with a clear description

## Review process

- All pull requests are reviewed before merging
- Changes may be requested before approval
- Not every contribution will be merged, especially if it does not fit the project direction

## Development setup

```bash
npm install
npm run compile
```

## Guidelines

- Keep changes focused and easy to review
- Follow the existing code style and structure
- Add or update documentation if needed
- Make sure your changes do not break the extension build

## What happens after approval

Once a pull request is approved, it can be merged and released in a future version of the extension.
